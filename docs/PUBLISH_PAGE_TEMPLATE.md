# 第七阶段：永久发布页模板

## 目标

总后台为每个导航站生成一份独立静态发布包。静态页面不依赖总后台、数据库或导航站在线，适合同时发布到：

- Cloudflare Pages 绑定的自定义永久域名；
- GitHub Pages 仓库地址。

页面明确展示并支持复制这两个收藏地址，不使用 `pages.dev` 地址作为对外入口。

## 管理端配置

每个站点必须配置：

- 自定义永久发布域名；
- GitHub Pages 提供的 `github.io` 原生发布地址。

自定义永久发布域名不能填写 `pages.dev` 原生地址；Cloudflare 项目只负责承载自定义域名。

可选配置包括 GitHub 仓库、Cloudflare 项目、防失联邮箱、Logo 地址、页面标题、页面说明和临时公告。Logo 必须使用浏览器可直接访问的 HTTP(S) 地址，生产环境建议使用 HTTPS。

只有两个发布地址都已填写时，管理端才允许创建生成任务。后端也执行相同校验，不能通过直接调用接口绕过。

## 入口数据

默认发布页入口按照以下顺序生成：

1. 当前导航站前台地址，标记为“主站”；
2. 总后台为该站计算出的有效节点，沿用统一节点管理的范围和排序规则。

如果 `publish_pages.payload.entries` 显式配置了入口，则使用该列表。入口只接受 HTTP(S)，重复地址只保留第一条，最多保存 100 条。

## 页面行为

- 打开页面后，各入口并行检查，单条最多等待 5 秒；
- 检查不阻塞页面渲染，也不阻塞“打开入口”按钮；
- 可访问入口按响应时间排在前面，失败入口保留并标记“暂不可用”；
- 检测使用 `no-cors`、不携带凭据、不发送 Referer；
- 自定义永久域名、GitHub Pages 地址和防失联邮箱均可复制；
- 更新时间固定按北京时间显示；
- 页面适配手机，键盘可操作，并尊重“减少动态效果”系统设置。

浏览器的跨域限制意味着前端检查只能判断请求是否成功发出或超时，不能读取目标站 HTTP 状态和正文。它是入口排序提示，不替代总后台节点健康检查。

## 生成产物

任务执行器将文件原子写入：

```text
var/publish-pages/<站点标识>/
├── index.html
├── 404.html
├── .nojekyll
├── _headers
└── publish-manifest.json
```

- `index.html`：主页面，样式和脚本全部内联；
- `404.html`：与主页面一致，避免静态托管路径错误后失去入口；
- `.nojekyll`：避免 GitHub Pages 对普通静态文件执行 Jekyll 处理；
- `_headers`：Cloudflare Pages 安全响应头；
- `publish-manifest.json`：格式版本、生成时间、双地址及 `index.html` 的 SHA-256。

GitHub Pages 不读取 `_headers`，因此关键内容安全策略同时写入 HTML 的 CSP Meta。页面不引用外部字体、脚本或样式，即使总后台离线仍可正常展示。

## 任务与部署边界

`publish.deploy` 当前完成的是“生成可部署静态包”。第七阶段不连接 Cloudflare 或 GitHub 账号，也不会自动推送仓库。后续部署阶段应读取任务结果中的 `directory`、`files` 和 `manifest`，分别执行：

1. 将同一份目录上传到 Cloudflare Pages 项目；
2. 将同一份目录提交到对应 GitHub Pages 仓库；
3. 对比远端页面与 manifest 中的 SHA-256；
4. 两端都成功后才把该版本标记为已发布。

生成目录已加入 `.gitignore`，不会误提交运行时产物。

## 安全边界

- 所有可点击地址只允许 `http:` 和 `https:`；
- 所有管理端文案在写入 HTML 前转义；
- 生成页面不包含总后台凭据、站点 Agent 凭据或后台入口；
- 外部链接使用新窗口、`noopener noreferrer` 和无 Referer；
- CSP 禁止框架嵌入、表单提交、摄像头、麦克风和定位权限；
- 发布包不执行广告代码，也不继承导航站的第三方统计代码。

## 验收标准

- 自定义永久域名和 GitHub Pages 地址同时可见、可打开、可复制；
- 生成页面中不出现 `pages.dev`；
- 总后台或导航站停止后，已生成页面仍能打开；
- 恶意标题、公告、Logo 或入口协议不能注入脚本；
- 手机端无横向滚动，按钮触控高度至少 44px；
- 五个静态文件完整生成，manifest 摘要与 `index.html` 一致。
